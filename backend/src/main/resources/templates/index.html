EcoGestión

Reporte y gestión de residuos sólidos en Pasto (Nariño) · Spring Boot + MongoDB

Cómo usar la API

Inicie sesión con POST /api/auth/login (JSON con correo y contrasena); la sesión queda en la cookie JSESSIONID. También se acepta autenticación HTTP Basic. Los errores se devuelven en formato Problem Details.
